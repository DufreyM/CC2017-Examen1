## Criterio de uso

- No registrar como propio un análisis que el equipo no pueda explicar.
- Contrastar cifras con el notebook ejecutado y con el Excel oficial.
- Anotar los cambios manuales hechos después de recibir una respuesta.
- Agregar una fila por cada tarea sustantiva, no una sola entrada genérica.
